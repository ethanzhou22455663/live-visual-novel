# AI Galgame

AI 实时生成剧情与对话的视觉小说引擎（Web/TS）。**开发中，当前为界面原型阶段。**

- 架构设计文档：`docs/architecture.html`（浏览器直接打开）
- 界面原型：`mock/ui.html`（浏览器直接打开；素材需自备，见 `mock/assets/README.md`）

## 合规须知（必读）

- `assets/` 与 `mock/assets/` 已被 `.gitignore` 排除：借用素材仅限**本机测试**，
  不得入库、不得截图/录屏公开。
- 语音音源仅可使用自录 / 授权录音 / 授权链清晰的 TTS，**禁止真实声优声音**。
- API key 只存用户本地，永远不入库。
