# 『黎明前打烊』——故事背景设定

> 本文档是创作设定档案,仅用于创作参考,不接入运行时;引擎实际消费的是 `assets/dawn/` 内容包。

## 一句话

全世界都标榜二十四小时营业,唯独车站前这家老旧便利店只在 0:00–5:00 开门——招牌上的「24」被划掉,
手写着「0時〜5時」。失眠的主角在这里上夜班,而深夜来店的客人,都是些回不了家的人。

## 舞台

**曙便利店**(あけぼの,「黎明」之意——却在黎明前打烊):车站前商店街尽头。昭和时代的陈设:
老式收银机、三排货架、靠窗吧台座、里间仓库兼账房。灯光永远偏暖,关东煮的锅永远冒着热气。

招聘启事写着「夜班店员·时薪三倍」,条件只有一句:**没有要回家的人。**

**主角·深見徹**:复读生,慢性失眠——夜里反正睡不着,不如干活。黑短发,疲惫眼神,心细,记性好得吓人,
吐槽都放在心里说。他没有要回家的人,所以他合格了。(无立绘、无配音,一人称视点)

## 店规三条(世界的硬规则)

1. **只在 0:00–5:00 营业。** 白天无论谁敲门,都不开。
2. **客人的请求,尽量接下。** 这是店的招牌,也是每一个故事的入口。
3. **店员不问客人的过去。** 客人自己开口,才可以听。

- 店规没有成文出处。被问到时,栞只说:「开店的时候就有了。」
- 第 2 条是故事的入口:每个委托/请求=一幕。
- 第 3 条是戏剧引擎:玩家(店员)眼看线索凑齐,却只能等客人自己开口——选择几乎都是
  「等她说 / 替她挡过去 / 装没听见」这类情感选择,而不是解谜。

## 怪异浓度旋钮

世界默认处于「浓度 1/3」:发生的事说不清是不是超自然,但永远可以解释成巧合,点到为止,绝不血腥。
世界书把浓度作为基调注入编剧;若某条线需要更高浓度(如栞线后段),由该线的秘密层显式放开。

## 都市传说集(可无限扩充)

- 打烊前结账的客人,不会再出现在这条街上。
- 曙便利店的关东煮汤底二十年没换过,也从没坏过。
- 在店里睡着的人,会被店里多留一会儿。

以上都只是传说。大概。

## 三面真相镜(世界之谜)

「这家店到底是什么」没有唯一标准答案——三条个人线各揭开一面镜子,大纲不钉死唯一真相:

| 线 | 真相镜 | 一句话 |
|---|---|---|
| 常盤栞 | **缓冲带** | 店是为「回不了家的人」设的过渡之地——而她是最早没能回家的那一个 |
| 三日月灯里 | **交换处** | 深夜的便当不是食物,是「被允许留在夜里」的凭证 |
| 宇佐美宵 | **故事的中转站** | 被写下来的客人,就能从夜里平安离开;店是故事走过夜里的桥 |

三条线可以互不兼容,也可以在终局互相呼应——由各线剧本自行决定。这正是「不钉死剧情」的写法:
世界书只给三面镜子,每条线拿一面照。

## 基调

**夜是温柔的;可怕的不是怪事,是天亮。**

全年龄。深夜食堂系的温柔与微苦:客人带着各自的夜晚进来,带走一点点能走到天亮的东西。
台词日常口吻,少用形容词,动作和停顿比形容词有用。
