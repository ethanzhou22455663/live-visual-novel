按拍流式：架构、依赖规则与工程规范

生成粒度：既不是一次性生成整篇，也不是每句一次 API 调用。 按「拍」（beat）生成——玩家每做一次选择，AI 用一次流式调用写出接下来 10~30 行剧情； 「句子」只是这段流内部的上屏和配音单位，不产生额外调用。 你的选择改变的是下一拍往哪写，已写好的内容永远不重新生成。

三种粒度，为什么只有一种成立

粒度怎么工作致命问题判定
全篇一次生成 一次调用写完整个故事 选项无法影响后续——正是你不要的「没有意义」；几万字输出必然崩坏 否决
每句一次调用 每写一句就请求一次 API 角色卡、世界书、摘要这些上下文每句都要重新注入一遍（×20 次/拍）；每句都付一次首 token 延迟，节奏稀碎 否决
每拍一次流式 导演发一次小指令，编剧一次流式调用连续输出 10~30 行；行边生成边上屏边配音 唯一代价：本拍第一句前有 2~4 秒等待，由打字机逐字显示 + 首句尽快合成填补 采用

「拍」= 一段连续剧情（十几句台词到一个场景），以弹出选项收尾。互动粒度是拍，显示/配音粒度是句，API 粒度也是拍——三层各司其职。

四层模型：核心业务、适配层、壳、协议

分层采用六边形（端口与适配器），按业务切成两个核心包（engine / director），不是横向三层。依赖方向永远指向 L0：

核心业务的操作性定义：换掉 PixiJS、React、GPT-SoVITS、DeepSeek 中的任何一个，L0 + L1 一行不改——只新增/替换对应适配器。凡是满足这条的东西才配叫核心业务；凡是依赖具体库或平台 API 的都归 L2 以下。

依赖倒置是强制的，不是口头约定——三重机械强制，违反任何一条直接编译失败或 CI 红灯：

  • 深导入封锁：每个包 package.json 的 exports 只开 "." 一个口（指向 src/index.ts）——跨包只能 import 公共 API，import 'engine/src/presentation/SpriteLayer' 这类路径直接解析失败
  • dependency-cruiser 进 CI：声明上面整张矩阵 + 包内规则（core 目录不得 import 适配目录）+ 禁环；pnpm 声明依赖本身也是一层（未声明的包根本装不进来）
  • tsconfig project references + tsc -b：类型层只看见允许引用的项目

运行时注入：构造函数注入，无 DI 框架——5 个包的规模上容器是过度设计。端口接口在 L0，实现类只在 L2/L3 出现，这就是依赖倒置的全部。

组合根：全仓库唯一，在 app

平台探测、具体实现的选择、对象图的装配，只允许出现在 app/src/bootstrap/。其余任何包看到的世界里只有接口：

// packages/app/src/bootstrap/createGameApp.ts —— 唯一的组合根
export function createGameApp(root: HTMLElement, config: UserConfig) {
  // 1. 平台探测 → 选适配器（具体实现唯一出现的地方）
  const http:  HttpPort    = isTauri() ? new TauriHttpPort() : new ProxyHttpPort('/llm', '/tts');
  const store: StoragePort = isTauri() ? new TauriFsAdapter() : new LocalStorageAdapter();

  // 2. 构造核心（它们只认 L0 接口，不知道上面选了什么）
  const bus      = new EventBus();
  const engine   = new EngineCore({ bus, sprites: new PixiSpriteLayer(root),
                                     text: new DomTextLayer(root), audio: new WebAudioBus(root),
                                     saves: new SaveSystem(store) });
  const director = new StoryDirector({ http, config });  // 内含 SSE 客户端+解析器+记忆
  const voice    = new VoiceScheduler({ http,
                    chain: [new GptSoVitsProvider(http), new CloudTtsProvider(http), new SilentProvider()] });

  // 3. 接线：协议事件是唯一粘合剂（engine/director/tts-bridge 之间无直接引用）
  bus.on('line:commit', e => voice.enqueue(e));
  voice.onClip(clip => engine.playVoice(clip));

  return new GameApp({ engine, director, voice, bus, ui: mountReact(root) });
}

域规定
TypeScriptstrict 全开；ESM（"type":"module"）；tsc -b project references；禁 any（确需则注释理由）；禁 // @ts-ignore（用 @ts-expect-error + 注释）；公共 API 全部显式返回类型
